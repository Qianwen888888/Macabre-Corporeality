# Macabre Corporeality

This repository contains the appendices accompanying a study of macabre corporeality in Charles Dickens's fiction and a temporally matched reference corpus of nineteenth-century British novels.

## Appendices

- **Appendix 1: Reference Corpus** — novels included in the temporally matched comparison corpus, organised by analytical stage.
- **Appendix 2: Body Lexicon** — the 76 corporeal lemmas used in the analysis.
- **Appendix 3: Macabre Anchor Lexicon** — the 66 candidate macabre anchors, including their analytical status and lexico-syntactic eligibility rules.
